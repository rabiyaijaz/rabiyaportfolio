RABIYA / CHARACTER STUDIO / EXPERIMENT 01

A little character.
A whole lot of possibility.

This is your first working 3D character prototype: a place to explore her personality before investing in the finished model.

The four parts of a game character

  1. Model: the surfaces you see — face, hair, clothes, glasses.
  2. Rig: joints that let the model move.
  3. Animations: short performances such as walking or waving.
  4. Controller: logic that chooses an animation and moves her through the world.

Three.js displays the model and plays the animations in your browser. The final, detailed model is usually authored in a 3D modeling application and exported as a GLB: a portable package of geometry, materials, and animations.

What you have now

A real, fully three-dimensional, simplified character, inspired by your references. She has chestnut waves, curtain bangs, black glasses, a nose hoop, a lip stud, a ribbed black turtleneck, flared trousers, and dark shoes. You can turn the camera all the way around her.

The prototype has articulated parts, rather than a continuous mesh with weighted skin. Her elbows, hands, face, and hair are simplified. It is an animation and interaction starting point, not a finished recreation of the reference. There is no automatic image-to-3D conversion in this project.

The studio loops each action for inspection, blends between actions, supports pausing and speed changes, and has an optional automatic waiting state after nine seconds. Reduced-motion settings start the preview paused and disable automatic waiting. Choosing an action explicitly starts playback.

Try the map behavior

Choose Explore a little, then choose a project, click the floor, or focus the scene and use WASD / arrow keys. She walks to the target and stops. Project markers display arrival cards as a navigation demonstration. They do not open your live case studies yet. This test area has a bounded floor, not obstacle avoidance or pathfinding.

Getting closer to your reference

  1. Establish consistent views. Use your current images as the design reference. Create neutral front, side, and back views with arms slightly away from the body. Unseen details need a design decision; they cannot be recovered exactly from these two views.
  2. Model and refine. Sculpt or commission a stylized character in Blender. Prioritize the face silhouette, eyes, glasses, curtain bangs, and large hair shapes. These make her recognizable. An image-to-3D service can supply a starting mesh, but it still needs inspection and cleanup.
  3. Rig and weight. Add a humanoid skeleton, then connect the skin to the bones. Test elbows, knees, shoulders, and trouser movement. Keep the glasses attached to the head and the mug attached to a hand socket.
  4. Animate. Author or retarget the seven actions. Make walking an in-place loop, keep feet consistent with travel speed, and key the mug to meet her lips. Add blink shapes and optional hair bones for polish.
  5. Export and integrate. Export one GLB with the same clip names, test it in Three.js, and connect arrival events to your existing portfolio routes.

For a browser portfolio, measure performance on a phone before choosing a polygon or texture budget. This procedural prototype contains many separate meshes; a production model should consolidate geometry and materials and use a weighted skeleton. This prototype’s animations cannot simply be applied to an unrelated skeleton: the replacement model needs its own clips or retargeting.

Using the exported file

Download the character and all seven clips. In your Three.js project, load it with GLTFLoader and play a clip with AnimationMixer. Keep movement of the root separate from the walk loop.

const gltf = await new GLTFLoader().loadAsync('/rabiya-prototype.glb');
scene.add(gltf.scene);
const mixer = new THREE.AnimationMixer(gltf.scene);
const walk = mixer.clipAction(
  THREE.AnimationClip.findByName(gltf.animations, 'walk')
);
walk.play();
// On each frame: mixer.update(deltaSeconds).
// Your controller moves gltf.scene.position toward its destination.

The local source also includes CharacterAnimator for transitions and an option to play an action once. For the production controller, use a small state system: idle → walk → arrive → wave → idle; waiting for a reply → wait; reply received → idle.

Files and running locally

From app/character-studio, run npm run dev to open the studio at http://127.0.0.1:5192. It reuses the installed Three.js and Vite dependencies in the parent app. Run npm run export after changes to the character, npm run check to verify the model and GLB, and npm run build for a static build.

Your existing portfolio files are not switched over to this prototype. The preview is a separate workspace for reviewing the look and interactions.
